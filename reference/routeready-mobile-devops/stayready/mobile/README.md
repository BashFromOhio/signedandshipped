# stayready/mobile · StayReady (React Native + Expo SDK 58)

One app, two fictional tenants (Cedar Cove, Harbor House). Shows tenant isolation (identity from the token)
and safe retries (one idempotency key per tap). Run: `local/11-react-native.sh` · Guide: [docs/local/level-11.md](../../docs/local/level-11.md)

`npm run typecheck` · `npm test` · `npx expo start`. Commit `package-lock.json`.
`app.config.snippet.json` is the OTA/runtimeVersion reference for drill 20.
