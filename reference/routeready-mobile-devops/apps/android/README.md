# apps/android · RouteReady (Kotlin)

A small, real Android app: demo sign-in → your routes → bus status (with data age and a STALE badge) → service alerts.
No third-party libraries. Built with AGP 8.13 / Gradle 8.14.3 / Kotlin 2.2 / JDK 17, compileSdk 36, minSdk 26.

Run it without installing anything system-wide: **[docs/local/README.md](../../docs/local/README.md)** (Levels 01–08).

| File | Why it matters |
|---|---|
| `app/build.gradle.kts` | Debug vs release API URL, `versionCode` from the allocator, release signing from environment variables |
| `app/src/main/java/org/routeready/parent/Models.kt` | Parsing + freshness. Contains a **known bug** you fix in Level 07 |
| `app/src/test/…/RouteStatusTest.kt` | Parses the real `contracts/fixtures`; one `@Ignore`d test for Level 07 |
| `app/src/debug/res/xml/network_security_config.xml` | Debug-only plain HTTP to `10.0.2.2` (the emulator's name for your computer) |
| `app/signing.gradle.kts` | The original reference snippet (now merged into `app/build.gradle.kts`) |

`gradlew` and `gradle/wrapper/*` are generated by `local/02-install-android-sdk.sh`. Commit them.
