# apps/ios (SwiftUI)

Not included in this reference. Create the Xcode project here (`RouteReady.xcodeproj`, scheme `RouteReady`)
with four screens: demo sign-in, assigned route, bus status with observation time and stale indicator, service alerts.

Simulator networking: the iOS simulator can reach the Mac's `localhost`. A physical device cannot;
use the Mac's LAN address or a tunnel, configured per build, never hardcoded.
